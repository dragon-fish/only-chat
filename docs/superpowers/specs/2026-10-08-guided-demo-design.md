# 演示模式（线性引导）

给开源访客的试玩版：打开 `/demo/` 无需注册，跟着一段受控的引导亲手操作真实界面，看完核心卖点后引向自行部署。全程不经过服务端、不调用任何模型、不保存任何数据，关掉页面即消失。

只做线性引导。访客不能自由输入，引导之外没有试玩环节。

## 1. 形态与入口

- 独立页面入口 `demo/index.html` + `src/client/demo/main.ts`，与主应用在同一次 `pnpm build` 中产出，部署在同一个 Worker 的静态资源里，地址 `/demo/`。静态资源请求不进入 Worker 代码（`run_worker_first` 只覆盖 `/api/*` 与 `/ws`），不触达 D1、DO、R2。
- 复用整套真实界面组件。路由使用 `createAppRouter(createMemoryHistory())`：地址栏始终是 `/demo/`，页面切换由引导驱动。
- 入口：README 顶部加「在线体验」链接（`https://chat.epb.wiki/demo/`），登录页加「先体验一下」链接到 `/demo/`。自托管实例同样自带 `/demo/`。

## 2. 假传输层

演示入口在挂载应用**之前**安装以下替换，主应用代码不感知演示模式。

### 2.1 fetch

包装 `window.fetch`：同源 `/api/*` 请求（含 Better Auth 的 `/api/auth/*`）交给剧本处理器，按方法与路径匹配响应；其余请求（静态资源、字体）照常发出。

**失败即拦截**：未命中剧本的 `/api/*` 请求返回错误响应并在控制台报错，**绝不调用原始 fetch**。演示页与真实应用同源，放行意味着带着当前浏览器的登录 cookie 访问真实数据。

### 2.2 WebSocket

替换全局 `WebSocket` 为假 socket：只接受 `/ws`，其他地址直接抛错。客户端发出的命令交给剧本播放器；服务端事件由剧本按时间表推送。

### 2.3 本地存储

`localStorage`、`sessionStorage` 换成内存实现，演示不读写真实应用的本地状态（主题、草稿等）。刷新即从头开始。

### 2.4 图片地址

`<img>` 加载不经过 fetch。演示入口改写 `api.attachmentUrl`，把剧本中的附件 id 映射到演示包内的静态图片，页面上不出现指向 `/api/` 的资源地址。

## 3. 剧本

### 3.1 初始数据

- 演示用户：普通角色（无站点管理入口），名为「演示用户」。
- 一个 mock 供应商与两三个模型，供模型选择器展示。
- 侧栏已有：一个 Project（含统一提示词与两条会话），一条带图片附件的历史会话。

### 3.2 事件生成

剧本用 TypeScript 手写。帮助函数把一段文字切块成流式事件，并生成推理块、工具调用块与工具结果；所有事件使用 `src/shared/ws.ts` 导出的类型。会话、消息 id 在剧本内固定。

### 3.3 步骤

引导库为 driver.js（宽松许可，版本与许可在计划阶段核实）。高亮区域之外不可交互；需要访客执行的动作（如点发送、点重新生成）是唯一的前进方式，其余步骤点「下一步」。

1. **欢迎**：介绍 Only Chat，进入新会话页。
2. **发送**：输入框已预填问题，访客点发送。
3. **推理与工具调用**：流式显示推理过程 → 一张联网搜索的工具调用卡片 → 流式输出回答。
4. **分支**：访客点「重新生成」，长出第二个回答；再在两个分支间切换。
5. **输入框能力**：依次高亮模型选择、推理强度、插件面板。仅展示，切换不生效。
6. **附件**：打开那条历史会话，看带图片附件的消息。
7. **Project**：高亮侧栏中的 Project，点进去看统一提示词。
8. **结束页**：见 3.5。

需要高亮的真实组件加 `data-tour="<name>"` 属性作为定位锚点。

### 3.4 剧本之外的操作

剧本未预期的 WebSocket 命令返回 `error` 事件「演示模式不支持该操作」，界面按现有的错误处理展示。

### 3.5 跳过与结束

任何步骤都可点「跳过引导」，直接到结束页。结束页是不可关闭的全屏浮层，三个按钮：

- **部署你自己的 Only Chat**：Deploy to Cloudflare 链接。
- **GitHub 源码**：仓库地址。
- **重新开始**：重新加载 `/demo/`。

## 4. 适配

桌面与手机都能走完全程。手机上侧栏是抽屉，涉及侧栏的步骤在进入时先打开抽屉。

## 5. 测试

- 剧本产生的每一帧服务端事件都能通过 `src/shared/ws.ts` 中服务端事件 schema 的校验。
- 假 fetch 对未命中剧本的 `/api/*` 请求返回错误且不调用原始 fetch；假 WebSocket 拒绝 `/ws` 以外的地址。

界面效果在本地实际走完引导验收（桌面与手机宽度各一遍）。

## 6. 不做

- 自由试玩与假 hub（消息树逻辑、mock 指令、`/help`）。
- 录制工具。
- 演示数据持久化。
- 多设备续流的演示。
- 独立域名部署。
