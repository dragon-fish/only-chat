`src/client/ui/` is mixed. shadcn-vue's distribution model is to copy source
into the consuming project rather than to ship a runtime library, so the
generic primitives there (`button/`, `dialog/`, `select/` and their like) began
as CLI output and carry unovue's copyright. The directory also holds components
written for this project — `bubble/`, `message/`, `message-scroller/`,
`attachment/`, `questionnaire/`, `marker/` — which do not.

`worker-configuration.d.ts` is generated output, regenerated by `pnpm types`.
It is tracked so the repository typechecks on checkout. Do not edit it, and do
not remove the Cloudflare and Microsoft notice inside it.

## Dependencies

Everything in `package.json` is fetched from the registry rather than vendored
here, and each package keeps the licence it publishes under.
`pnpm-lock.yaml` is the authoritative list of what a build actually resolves.

This matters at deployment, not just in development: `pnpm build` bundles
dependency code into the Worker artifact you deploy. **The Corresponding Source
the AGPL asks you for is this repository plus its lockfile**, which is what
lets someone reproduce that artifact.
